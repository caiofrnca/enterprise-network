## Automation Checks

### Overview
This script performs basic health validation across the enterprise lab using Netmiko.

See `outputs/` for example validation reports generated by the automation script. I validated both healthy and failure conditions.

### Functions
- Connects to routers and switches
- Runs protocol and redundancy validation commands
- Checks BGP, OSPF, HSRP, EtherChannel, trunks, and routing state
- Flags outputs as PASS, WARN, or FAIL
- Saves per-device reports in the `outputs/` directory

### Purpose
The goal is to reduce manual verification effort and improve consistency during troubleshooting and post-change validation.
